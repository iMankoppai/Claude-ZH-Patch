# 界面术语

| 原文 | 译法 | 范围 |
| --- | --- | --- |
| Preparing session... | 正在准备会话… | 精确 prompt 初始化显示 |
| Currently streaming message | 正在接收回复 | 流式文章无障碍标签 |
| Request / Response / Error | 请求 / 响应 / 错误 | 工具抽屉固定标题 |
| Something else | 其他选项 | 固定普通问题输入标签 |
| Turn into skill | 转为技能 | 固定任务菜单动作 |
| Schedule | 计划 | 固定菜单/表头 |
| Type to filter | 输入以筛选 | 斜杠菜单固定提示 |
| Compacting… | 正在压缩… | 上下文状态 |

Claude、Cowork、Code、模型、工具和技能名称保持原文。命令、路径、生成问题/选项、用户正文和工具输出不采用此表替换。
